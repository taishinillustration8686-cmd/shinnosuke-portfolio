# お問い合わせフォームを「本当に届く」ようにする手順

所要時間およそ10分。費用はかかりません。Googleアカウントだけで完結します。

## なぜ設定が必要か

いまのフォームは、送信ボタンを押すと**メールソフトが開くだけ**です。
相手がそこで送信ボタンを押さなければ何も届きません（スマホでメールアプリを設定していない人は、そもそも何も起きません）。
また、この方式では**送信者への控えメールを送ることができません**。

そこで、Googleの無料サービス（Apps Script）を「送信係」として挟みます。これで、

1. 自分あてに通知メールが届く
2. 送信してくれた相手にも控えのメールが自動で届く
3. スプレッドシートに記録が残る（メールを消しても台帳が残る）

がすべて自動になります。

---

## 手順

### 1. スプレッドシートを作る

1. https://sheets.new を開く（新しいスプレッドシートができます）
2. 左上のファイル名を「ポートフォリオ お問い合わせ」などに変更

### 2. スクリプトを貼り付ける

1. メニューの **拡張機能 → Apps Script** をクリック
2. 最初から書いてある `function myFunction() {}` を**すべて削除**
3. 同じフォルダにある **コード.gs** の中身を全部コピーして貼り付け
4. 左上のプロジェクト名を「お問い合わせフォーム」に変更し、**保存**（Ctrl+S / ⌘S）

### 3. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ** をクリック
2. 歯車マーク（種類の選択）→ **ウェブアプリ** を選ぶ
3. 次のように設定する
   - 説明：`お問い合わせフォーム`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員** ← ここが重要です
4. **デプロイ** をクリック
5. 「アクセスを承認」→ 自分のGoogleアカウントを選択
6. 「このアプリは確認されていません」と出たら、**詳細 → （プロジェクト名）に移動** → **許可**
   （自分が作ったスクリプトなので問題ありません）
7. 表示された **ウェブアプリのURL** をコピー
   （`https://script.google.com/macros/s/……/exec` という形式）

### 4. URLをサイトに設定する

`js/main.js` の上のほうにある次の行に、コピーしたURLを貼り付けます。

```javascript
const FORM_ENDPOINT = '';
```
　↓
```javascript
const FORM_ENDPOINT = 'https://script.google.com/macros/s/……/exec';
```

貼り付けたら、以下を実行して本番に反映します。

```bash
cd "/Users/taimakotonoten/Claude Code/出力物/Webサイト/しんのすけポートフォリオ" && git add -A && git commit -m "お問い合わせフォームの送信先を設定" && git push
```

**URLを教えていただければ、この作業と動作テストはこちらで行います。**

---

## 動作テスト

1. 公開サイトのフォームに、自分のメールアドレスを入れて送信する
2. 「送信しました」と画面に出る
3. 自分あての**通知メール**が届く
4. 入力したアドレスに**控えメール**が届く
5. スプレッドシートに1行増えている

この4つが揃えば完成です。

---

## 補足

- **迷惑メール対策**：人には見えない入力欄を用意してあり、そこが埋まっている送信（自動プログラムによるもの）は無視します。
- **送信できる数**：Gmailの無料アカウントで1日100通まで。お問い合わせ用途なら十分です。
- **控えメールが迷惑メールに入る場合**：相手側の環境によってはあり得ます。気になる場合はGoogle Workspace（独自ドメインのメール）を使うと改善します。
- **文面を変えたいとき**：`コード.gs` の「控え（自動返信）」の部分を書き換えて、再度 **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ** すれば反映されます。
